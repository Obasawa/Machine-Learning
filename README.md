Answers to Theory
1. Supervised Machine Learning is a machine learning technique that uses labeled data to train AI
2. Unsupervised Machine Learning is providing the model with data and let it draw out patters for grouping

3. The main difference between supervised and unsupervised machine learning is labels. Supervised learning has labels making the model learn from correct answers. Unsupervised learning doesn’t have labels so the model has to find patterns on its own.

4. Linear Regression is considered supervised learning because we train it using data where the correct answer is already known

5. K-Means discovers the groups hidden in the data since the data has no labels

6. Fit() trains the model by finding patterns in the given data while Predict() gives the output on the new input given after learning the patterns

7. Real World scenario: Supervised ML - Loan approvals, where the model learns from customer behavior 
Unsupervised ML - Fraud detection, checks on amount deposit/ withdrawal that look totally different from normal pattern
